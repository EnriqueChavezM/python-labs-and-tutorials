# 1. Importar Módulos

Importar un módulo significa traer código preescrito *(por ti o por la comunidad)* a tu archivo actual para no tener que reinventar la rueda. Un módulo puede ser otro archivo .py o una librería de Python.

## Importar el Módulo Completo (``import``)

Trae todo el contenido del módulo. Para usar sus funciones, debes anteponer el nombre del módulo seguido de un punto.

***Sintaxis***

```python
import Nombre_Modulo
```

---

## Importar Función Específica (``from ... import ...``)

Extrae solo la función, clase o variable que necesitas. Así no tienes que escribir el nombre del módulo cada vez que la usas.

***Sintaxis***

```python
from Nombre_Modulo import Funcion_Variable
```

---

## Importar con un Apodo/Alias (``import ... as ...``)

Le da un nombre más corto o conveniente al módulo. Es una práctica estándar para librerías muy usadas.

***Sintaxis***

```python
import Nombre_Modulo as  alias
```
