# 4. Polimorfismo

Es la capacidad que tienen objetos de diferentes clases para responder al mismo método, ejecutando cada uno su propio comportamiento.
Gracias al tipejo dinámico de Python (Duck Typing), no necesitas interfaces complejas: basta con que diferentes clases tengan un método escrito exactamente con el mismo nombre.

## ¿Por qué es útil el polimorfismo?

- **Flexibilidad:** Puedes agregar nuevas clases sin modificar la funcion
- **Código más limpio:** Evitas llenar el programa con múltiples estructuras (``if/else``)
