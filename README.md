# Python Learning Journey 🐍

Bienvenido/a a mi repositorio personal dedicado al aprendizaje, práctica y documentación del lenguaje **Python**. En este espacio voy consolidando conceptos teóricos, ejercicios prácticos, proyectos pequeños y notas sobre desarrollo de software, manipulación de datos y automatización.

---

## 📌 Objetivos del Repositorio

- **Documentar mi progreso:** Registrar de manera ordenada el avance en conceptos fundamentales e intermedios.
- **Práctica constante:** Resolver ejercicios algorítmicos, retos de lógica y manipulación de datos.
- **Proyectos aplicados:** Crear scripts funcionales enfocados en automatización, APIs e Internet de las Cosas (IoT).
- **Control de versiones:** Practicar buenas prácticas con Git/GitHub (commits semánticos, ramas y documentación limpia).
